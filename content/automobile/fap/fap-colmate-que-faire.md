# FAP colmaté : que faire ?

Un FAP colmaté signifie que le filtre à particules est trop chargé pour se régénérer correctement.  
Ce problème est fréquent sur les véhicules diesel qui roulent souvent en trajets courts.  
Voici les signes, les causes et les solutions simples avant d’envisager une intervention coûteuse.

---

## Les signes d’un FAP colmaté

### 1. Perte de puissance
Le moteur peine à monter dans les tours.  
La voiture semble “étouffée”.

### 2. Voyant moteur ou voyant FAP
Le système antipollution détecte une pression anormale dans le filtre.

### 3. Régénérations très fréquentes
Le véhicule tente de brûler les particules, mais n’y parvient pas.

### 4. Ventilateur qui tourne longtemps
Même moteur coupé, le ventilateur continue pour refroidir les gaz.

### 5. Consommation plus élevée
Le moteur injecte davantage de carburant pour tenter une régénération.

---

## Pourquoi le FAP se colmate ?

### 1. Trajets courts répétés
Le moteur n’atteint pas la température nécessaire pour régénérer.

### 2. Régénérations interrompues
Couper le moteur pendant une régénération empêche le cycle de se terminer.

### 3. Vanne EGR encrassée
Elle augmente la production de particules.

### 4. Sondes défaillantes
- sonde de température  
- capteur de pression différentielle  
- sonde lambda  

Un défaut empêche la régénération.

### 5. Carburant de mauvaise qualité
Certains carburants produisent plus de suies.

---

## Que faire en cas de FAP colmaté ?

### ✔ 1. Faire un trajet de 20 à 30 minutes
À vitesse stabilisée, moteur chaud.  
Cela peut suffire si le colmatage est léger.

### ✔ 2. Éviter les trajets courts pendant quelques jours
Le temps que le système se stabilise.

### ✔ 3. Vérifier le niveau d’huile
Un niveau trop haut empêche la régénération.

### ✔ 4. Vérifier la présence d’un voyant moteur
S’il est allumé, une sonde peut empêcher la régénération.

### ✔ 5. Passer un diagnostic (valise)
Le diagnostic identifie :
- FAP trop chargé  
- régénération impossible  
- sonde défaillante  
- EGR encrassée  

### ✔ 6. Nettoyage FAP (si nécessaire)
Deux solutions :
- nettoyage FAP à l’hydrogène  
- nettoyage FAP démonté (atelier spécialisé)

### ✔ 7. Remplacement (cas extrême)
Uniquement si le FAP est totalement bouché.  
C’est rare si le problème est traité à temps.

---

## Peut-on rouler avec un FAP colmaté ?

### ✔ Oui, mais avec prudence  
Le véhicule peut passer en **mode dégradé**.

### ✔ Risques si on continue longtemps
- perte de puissance  
- surchauffe  
- casse turbo  
- casse catalyseur  
- intervention coûteuse

Le voyant d’airbag du Toyota Verso peut s’allumer pour plusieurs raisons : connecteur sous le siège, capteur défaillant, tension électrique instable. Ce voyant est important, car il concerne la sécurité. Une approche simple permet de comprendre l’origine du problème et d’agir sans stress.

## Définition simple
Le voyant d’airbag indique un dysfonctionnement dans le système de retenue : airbags, prétensionneurs, capteurs.  
Quand il s’allume, le système peut être partiellement ou totalement désactivé.

## À quoi ça sert ?
Ce voyant sert à :
- signaler un problème de sécurité,  
- éviter un déclenchement incorrect,  
- prévenir une absence de déclenchement en cas d’accident.

## Comment ça fonctionne ?
1. Le calculateur vérifie en continu les capteurs et connecteurs.  
2. Si une anomalie est détectée (mauvais contact, tension instable, capteur HS), le voyant s’allume.  
3. Un lecteur OBD2 permet de lire le code défaut pour identifier la zone concernée.  
4. Les causes les plus fréquentes sur le Verso :  
   - connecteur jaune sous le siège conducteur,  
   - connecteur sous le siège passager,  
   - tension batterie trop faible,  
   - capteur de choc défaillant.

## Points importants à retenir
- Ne pas ignorer ce voyant : il concerne la sécurité.  
- Souvent, le problème vient d’un simple connecteur.  
- Un lecteur OBD2 aide à identifier rapidement la cause.

## Exemple concret
Tu démarres ton Toyota Verso et le voyant d’airbag reste allumé.  
Tu vérifies sous le siège conducteur : le connecteur jaune est légèrement tiré.  
Tu le reclipsses correctement, tu redémarres : le voyant s’éteint.  
Si le voyant persiste, un lecteur OBD2 permet de lire le code exact.

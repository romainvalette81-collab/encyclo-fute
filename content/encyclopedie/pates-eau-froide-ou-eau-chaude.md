## Résumé
Faut-il mettre les pâtes dans de l’eau froide ou attendre que l’eau soit chaude ?  
La réponse semble évidente… mais elle repose sur **la physique**, **la texture**, **l’amidon** et **l’efficacité énergétique**.  
Voici la vérité futée.

---

## 1. Ce que font la plupart des gens
La majorité des foyers :
- font chauffer l’eau,  
- attendent l’ébullition,  
- ajoutent les pâtes ensuite.

C’est la méthode traditionnelle, enseignée partout.

---

## 2. Cuisson dans l’eau chaude : les avantages
Mettre les pâtes dans l’eau bouillante permet :
- **une cuisson uniforme**,  
- **une activation rapide de l’amidon**,  
- **une texture plus contrôlée**,  
- **moins de collage**,  
- **un temps de cuisson précis**.

C’est la méthode recommandée par :
- les chefs,  
- les fabricants de pâtes,  
- les écoles culinaires.

---

## 3. Cuisson dans l’eau froide : est-ce possible ?
Oui… mais ce n’est pas optimal.

Mettre les pâtes dans l’eau froide puis chauffer :
- rallonge le temps de cuisson,  
- libère plus d’amidon → risque de collage,  
- donne une texture moins régulière,  
- nécessite plus de surveillance.

Cette méthode est utilisée dans certains restaurants pour des cuissons “à l’avance”, mais ce n’est pas la meilleure pour un foyer.

---

## 4. Physique : pourquoi l’eau chaude est meilleure ?
L’eau bouillante :
- gélatinise l’amidon immédiatement,  
- empêche les pâtes de se décomposer,  
- stabilise la structure interne,  
- réduit les variations de texture.

L’eau froide chauffe progressivement → l’amidon se libère trop tôt → les pâtes collent.

---

## 5. Consommation d’énergie : un point souvent oublié
Mettre les pâtes dans l’eau froide **n’économise pas d’énergie**.

Pourquoi ?
- Le temps de chauffe est plus long,  
- La libération d’amidon augmente la mousse → risque de débordement → baisse de puissance → rallongement du temps,  
- Le résultat final demande parfois un rinçage → gaspillage d’eau.

L’eau chaude reste la méthode la plus efficace.

---

## 6. La vérité futée
La meilleure méthode :
- Faire chauffer l’eau,  
- Ajouter le sel **avant** les pâtes,  
- Mettre les pâtes **dans l’eau bouillante**,  
- Remuer les 20 premières secondes.

L’eau froide fonctionne… mais donne un résultat moins bon.

---

## Conclusion
Pour des pâtes qui ne collent pas, une cuisson uniforme et une texture maîtrisée, l’eau chaude est la meilleure option.  
L’eau froide est possible, mais elle n’apporte aucun avantage réel.

---

## Fiche rapide
- **Eau chaude** : meilleure texture, moins de collage  
- **Eau froide** : possible mais moins bon  
- **Physique** : amidon = clé de la cuisson  
- **Énergie** : eau chaude = plus efficace
